# 问卷与制作流程

## 四步启动问卷

以聊天形式逐步呈现，每轮只发当前一步，显示「第 1 步 / 共 4 步」这类简短进度。用户可以直接用一句话回答，也可以用选项字母。已在需求、文件或先前回复里说清的内容直接带入。若当前步已经完整，告知采用的结果并继续到下一步。遇到只影响局部的缺项，先完成能推进的工作。

### 第 1 步 · 你想做什么视频

**给用户看**

> 用自己的话说说你想做什么视频。可以写给谁看、希望看完以后他们能做什么。
>
> 例如「我想做一条给第一次接触机械臂的人看的课程视频，带他们一步步采集数据、训练模型、部署到真机。」

**什么时候确认**　直接采用清楚的目标。如果「学会操作」和「了解课程后报名」都可能成立，且用户没有明确表达，就只追问这一个差异。通过描述判断观众基础、制作者希望参与的程度和能否自行接手工程。只有判断会改变下一步时，才补问相关信息。

### 第 2 步 · 确定视频规格

**给用户看**

| 项目 | 选项 |
| --- | --- |
| 画幅 | A 横版 16:9 · B 竖版 9:16 · C 横版 4:3 · D 竖版 3:4 · **E 多个画幅，请直接说需要的比例** · F 按发布场景推荐 |
| 时长 | A 30 秒以内 · B 约 1 分钟 · C 1–3 分钟 · D 3 分钟以上 · E 自填 · F 按步骤推荐时长 |
| 语言 | A 中文 · B 英文 · C 中英各出一版 · D 中英同屏 · E 其他 |
| 声音 | A 保留录制原声 · B 加旁白 · C 配乐和音效 · D 静音。A、B、C 可按需组合 |
| 字体 | A 请指定品牌规范中可商用的字体，填写字体名或上传字体文件。没有指定字体时，由 Skill 提供可商用候选供你选择 |

> 可以像这样回复「16:9 和 3:4，按步骤推荐时长，中文，保留原声，字体用 Noto Sans。」

**什么时候确认**　用户的明确回答直接生效。按步骤推荐的时长在分镜中给出，多个画幅在样段前注明先预览哪一个。字体应在制作画面前确认具体字体，涉及中文时同时核对字形覆盖和实际使用的字体文件。语言涉及口播和画面文字分别交付时，才补问两者的对应关系。

### 第 3 步 · 先把现有素材发过来

**给用户看**

> 把已有的素材一起发来就好。大纲、网页链接、讲稿、口播、实拍和录屏都可以混着发，文件名暂时不用改。有必须使用的素材，可以顺手标一句。

收到后，先给一份短清单，注明「可以直接用」「建议先处理」「缺哪一段」。补素材时说清楚要拍或录什么，例如「补一段从点击停止录制到看到保存结果的连续录屏」。未知内容写待识别，避免根据文件名推断操作结果。

| 素材 | 处理建议 |
| --- | --- |
| 实拍 | 先检查抖动和主体位置，建议防抖加二次构图。确认手、设备状态和关键动作都看得见。 |
| 录屏 | 按章节和操作顺序统一命名。核对按钮、参数、运行结果是否清楚，必要时补录完整动作。 |
| 口播 | 建议先粗剪，去除口误、多余停顿与明显噪音，保留解释操作所需的停顿。保留原始音轨备查。 |
| 大纲、讲稿和网页 | 用于核对步骤、术语和说明。标出讲稿与实录不一致且会影响教学的地方。 |

**统一命名是必要步骤。** Skill 给出当前文件名与工作名的对应表，在可读写的工作副本上整理，保留原始素材和既有工程的引用。暂时只能访问链接时，先在素材清单中分配工作名并记录来源。命名按「章号－步骤号－动作－素材类型」，整课资料用 00，重复拍摄可加「第 01 条」。机械臂课程示例：

| 工作名 | 对应内容 |
| --- | --- |
| 00-全课-课程大纲 | 全课结构 |
| 00-全课-网页链接 | 原始网址保存在素材清单 |
| 00-全课-讲稿 | 全课讲稿 |
| 00-全课-口播原声.wav | 全课口播音频 |
| 01-02-开始采集-录屏.mp4 | 第 1 章第 2 个操作的屏幕录制 |
| 01-03-真机示范-实拍-侧机位.mp4 | 第 1 章第 3 个操作的侧机位 |
| 02-训练机械臂-录屏.mp4 | 尚未拆分的第 2 章录屏 |
| 03-部署机械臂-实拍.mp4 | 尚未拆分的第 3 章实拍 |

具体步骤号和描述以素材内容为准，工作副本保留实际扩展名。多机位素材有同步依据时，使用同一操作编号并区分机位。

**什么时候确认**　完成盘点后展示归类和缺口。普通重命名和可逆整理直接推进。操作次序互相矛盾、关键结果缺失、必须使用的素材无法辨认时，请用户只处理对应的一项。

### 第 4 步 · 你想先看什么

**给用户看**

> - A 先看静态视觉参考 **（新手友好）**
> - B 先看分镜，确认内容和镜头顺序
> - C 先看一段动态样段，感受节奏
> - D 方向已经明确，直接看第一版

**什么时候确认**　用户选中一项就按该入口推进。推荐 A → 分镜 → 动态样段给想逐步确认的用户。选 B 就直接展示分镜。选 C 就用内部草图或简版分镜推进样段。用户明确让 Skill 直接做第一版时，合并中间确认，只在关键内容缺失或影响真实操作时提出具体问题。

问卷、素材盘点与预览选择共同提供工具决策所需的信息。用户可以直接选想看的东西。Agent 根据任务在后台选择制作工具，具体规则见[分流、预览与交接](routing-and-preview.md)。

## 从静态参考到成片

| 阶段 | 给用户看什么 | 确认与推进条件 |
| --- | --- | --- |
| 静态视觉参考 | 2–3 个整体视觉方向，尽量用同一段真实内容和同一画幅。每个方向展示一张实际内容页，可再补一张章标题页。让用户看清色彩、字号层级、录屏和实拍怎么放、操作提示和字幕在哪里。 | 用一句「选 A、B 或 C，也可以说你想保留哪一项」收口。选定后记录具体视觉选择，进入分镜。 |
| 分镜 | 一张简表，按章展示镜头、估计时长、画面与声音、操作和结果。逐个标出关键实拍插入点、对应素材和确有影响的缺口。多画幅说明关键界面在另一比例怎样重新排版。 | 请用户核对步骤顺序和结果是否正确。「照这个做样段」即进入样段。细小镜头调整可随制作处理。 |
| 送审前自审与修改 | 后台完成，用户直接看到修过的样段或首版。 | 按下文自审并修正实际发现的问题，再发送用户预览。 |
| 动态样段 | 一段可直接播放的预览，先做一个画幅。教程可选「开始操作 → 关键动作 → 回看结果」，宣传片选能代表本片叙事和视觉的完整片段。用真实素材和约定音轨检查构图、文字、节奏及音画同步。素材有缺口时在对应位置标清占位。 | 让用户判断三个体验问题即可：看得清吗、跟得上吗、关键动作对得上吗。样段确认后，按原定制作范围推进。已约定制作全片时，把样段验收过的做法扩展到全片。反馈集中在哪个镜头就改哪个镜头。 |
| 第一版与修改 | 可播放的全片预览，附少量时间码说明。每轮带上最新版本和本轮修改的位置。交付多个语言或画幅时说明这轮要验收哪一版。 | 局部意见直接修改。只有涉及教学内容、风格方向或已确认的规格才回到对应决定。用户明确确认当前全片版本时，记录定稿。 |
| 按需交付 | 按已约定的范围交付，例如指定画幅的 MP4、样段，或成片加可编辑工程。用户要求的其他交付物也在这里核对。 | 已明确交付物就按需交付。用户未提剪映草稿时，等全片定稿后再问一次「要不要我再把定稿打包成可编辑的剪映草稿？」用户明确只要成片、明确要草稿，或本轮只做到样段时，直接执行对应范围。 |

### 确认记录（后台）

收到确认或修改时，在同一份项目记录中更新「当前阶段｜对应版本｜已确认的决定｜仍由 Agent 处理的细节｜待补素材或待确认项」。继续制作时直接带入已有决定。常规构图、节奏与镜头细节由 Agent 处理。用户改主意时，只更新受新指令影响的范围。用户回复「可以」时，按上一轮给他看的内容和提请确认的事项判断范围。只有多个决定都可能被指代、且会走向不同制作结果时，才补问一个具体问题。

| 用户反馈 | 记录的决定与下一步 |
| --- | --- |
| 「整体用 A，真机镜头想要 C 的感觉」 | 确认整体和局部视觉方向，后续分镜带入这两个选择。 |
| 看完分镜后说「照这个做」 | 确认这版分镜并进入约定的动态样段。 |
| 看完 V3 后说「差不多了，给新手用户够了」 | 记录 V3 达到本次试跑的最低交付水准，按约定范围推进。如果已约定全片，就进入全片制作，并重新核对课程步骤、关键型号和画面文字的覆盖。 |
| 看完全片后说「这版定了，可以导出了」 | 记录已确认的全片版本、语言和画幅，再按约定交付。 |

### 送审前自审与修改（后台）

样段或首版完成后，先以第一次接触内容的观众视角按正常速度完整看一遍，配有音乐或音效时一并检查。对照已确认的分镜和视觉方向，在内部用时间码记下「观众看到什么、哪里容易看错、准备怎么改」。重点观察三个问题。

- **信息有没有被读懂。** 关键界面、训练输出、图表和文字都要让观众快速看到结果。看不清的素材裁到能读清的部分，或用核对过的简短文字概括真实结果。
- **视线有没有跟到主体。** 检查字幕或标题退场后，构图是否还把眼睛带向关键动作。无信息的大块画面、遮挡和偏离视线的标注，优先通过重新构图和调整字幕位置解决。
- **镜头为什么要接在一起。** 遇到从参考片或旧版沿用的转场，先讲清观众在前一镜知道了什么、下一镜要亲眼看到什么，再选切法。前后关系清楚时，干净的切镜可以让动作和音乐承担过渡。

先修妨碍理解或注意力的问题，再调整缓动与音效。修改后复看受影响的镜头和前后接点，核对实际导出的版本。发现影响观看的问题就修到位再送审。确因素材或播放能力无法核实的地方，用一句话标清。用户仍只收到一条可播放预览和一两句好回答的反馈提示。

**[剪映草稿的处理](jianying-draft.md)**　用户需要时，复用现有 Skill 的素材整理、多轨时间线和验收流程。提前明确要求可编辑时，制作中保留剪辑、文字、录屏、实拍和音轨对应关系，避免定稿后返做。交付时说明哪些层可在剪映里继续调整、哪些动效已经合成，并区分文件检查与在目标剪映环境中实际打开、播放或导出的验证。成片按约定检查画幅、语言、音频和导出文件。
