# Final Take · v0.6

Final Take 是一个基于 [Agent Skills 开放标准](https://agentskills.io/specification) 的视频制作 Skill。提供一个想法或已有素材，Agent 会和你确认想做的视频，从画面方案、分镜和样段做到成片。也可以直接精剪口播、录屏教程和已有剪映草稿，按需交付 MP4 或可编辑工程。

**[看完整的第一次使用指南](docs/getting-started.md)** · [查看按需安装的工具](references/install-on-demand.md)

## 三步开始

1. **安装。** 在支持 Agent Skills 的客户端里发送下面这句话，也可以[按你使用的客户端手动安装](docs/getting-started.md#1-怎样安装并开始)。

   ```text
   请从 https://github.com/MilesHuang-EDIT/video-workflow-guide 安装 Final Take。SKILL.md 在仓库根目录（路径 .），请按当前客户端的方式安装整个目录，目录名用 video-workflow-guide。
   ```

2. **说你要做什么。** 有素材就把能访问的文件或链接一起发来。下面是一句可以直接改的例子。

   ```text
   用 video-workflow-guide 帮我做一支给新手看的机械臂课程宣传片。横版，中文，大约 1 分钟。我有课程网页、录屏和实拍，想先看几个画面风格。
   ```

3. **看一段再决定。** 可以先选静态画面风格，再看分镜和动态样段。样段是一小段可以播放的试做视频，确认字幕、节奏和声音都合适之后，再按你的要求继续做全片。

你也可以先说「我只有一个想法」或「我还不知道用横版还是竖版」，让 Agent 根据目标给建议。素材可以混着发，Agent 会在工作副本里整理。首次安装从这一个 Skill 开始，剪映及其他制作工具根据任务需要再安装。

## 已经录完了？直接说要改什么

**精剪口播**

```text
用 video-workflow-guide 精剪这期口播。我有原视频和 SRT 字幕。去掉口误和明显停顿，保留原声和讲解顺序，交 MP4 和可编辑剪映项目。
```

**继续改剪映草稿**

```text
用 video-workflow-guide 继续剪这个剪映草稿。先在副本上调整第二章的字幕和原声音量，给我看改过的片段再定稿。我用的是剪映专业版桌面端。
```

## 最后会拿到什么

| 你想要的结果 | 可以约定的交付 |
| --- | --- |
| 先验证方案 | 一个可播放的短样段，用来检查画面和节奏 |
| 发给别人看或上传平台 | 按约定尺寸、语言和音轨导出的 MP4 成片 |
| 自己或团队还要继续修改 | 可编辑工程，说明怎么打开、哪些内容可改，以及在目标应用里实测过什么 |

只需要 MP4 时可以直接说。要继续在剪映里改字、换素材或调声音，就补一句「需要可编辑剪映草稿」，并告诉 Agent 你用哪个版本或平台。[剪映草稿怎么交接](docs/getting-started.md#拿到成片或剪映草稿后怎么检查)
